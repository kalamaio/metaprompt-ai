Questo sito

Il sito è una raccolta di pagine statiche pubblicate tramite GitHub Pages. Non contiene moduli di registrazione, strumenti di pagamento o un sistema di account proprio. GitHub può trattare dati tecnici necessari a erogare il servizio secondo le proprie condizioni e informative.

Utilizzo del plugin

MetaPrompt AI v1.2 è un plugin basato su istruzioni (skill), senza un server applicativo esterno dichiarato nel pacchetto. Le conversazioni avvengono nell'ambiente ChatGPT e sono soggette alle impostazioni e alle informative applicabili della piattaforma. Non possiamo dedurre da questo solo fatto tutte le modalità di trattamento dei dati della piattaforma.

Assistenza tramite GitHub

Se apri una issue pubblica, il testo e le informazioni del tuo profilo GitHub potrebbero essere visibili pubblicamente. Evita di includere informazioni personali o riservate.

Informazioni da confermare

Prima della pubblicazione del plugin devono essere verificati il titolare e i recapiti per la privacy, le eventuali ulteriori modalità di raccolta e conservazione, la gestione delle richieste sui dati e le disposizioni applicabili. Questa pagina non dichiara verificati aspetti ancora da confermare.
