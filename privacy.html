MetaPrompt AI

MetaPrompt AI v1.3.0 è un plugin basato su istruzioni. Non richiede account aggiuntivi, non usa server o servizi esterni gestiti dallo sviluppatore, non gestisce pagamenti e non raccoglie o conserva dati personali tramite un'infrastruttura propria.

Conversazioni in ChatGPT

Le conversazioni avvengono nell'ambiente ChatGPT. Le modalità con cui la piattaforma tratta i dati dipendono dalle sue impostazioni e informative; questa pagina non descrive né sostituisce le informative della piattaforma.

Sito informativo

Il sito è composto da pagine statiche pubblicate tramite GitHub Pages. Non contiene moduli di registrazione, account, pagamenti o strumenti di analisi gestiti dallo sviluppatore. GitHub può trattare dati tecnici necessari a fornire il proprio servizio secondo le proprie condizioni e informative.

Assistenza tramite GitHub

Se apri una issue pubblica, il testo inserito e le informazioni del tuo profilo GitHub possono essere visibili pubblicamente. Non inserire password, dati personali di terzi, documenti riservati, conversazioni private o altre informazioni sensibili.

Condivisione e conservazione

MetaPrompt AI non dispone di un archivio o di un database proprio per ricevere, condividere o conservare dati degli utenti. Eventuali contenuti inviati volontariamente tramite ChatGPT o GitHub sono soggetti alle condizioni delle rispettive piattaforme.

Contatti

Per domande generali sul progetto consulta la pagina di assistenza. MetaPrompt AI non offre assistenza tramite email pubblica.
